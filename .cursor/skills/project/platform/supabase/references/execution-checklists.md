# Execution Checklists

## Read-Only Investigation
- Confirm project and branch.
- Gather current state with read-only calls.
- Capture exact evidence for conclusions.

## Schema Change
- Baseline advisors captured.
- Migration plan prepared.
- Migration applied once.
- Post-change validation completed.
- Advisors re-run and reviewed.

## Data Fix
- Predicate is explicit and narrow.
- Dry-run equivalent read executed.
- Row impact confirmed.
- Follow-up read confirms intended state.

## Edge Function Update
- Existing behavior reviewed.
- Deployment target confirmed.
- Function deployed.
- Invocation/result validated.

## Final Report
- Scope: project + branch.
- Actions: ordered list.
- Validation: passed/failed evidence.
- Risks: remaining concerns.
- Recommendation: clear next step.
