# Advisor Workflow

Load this only when the task is security/performance review, risk triage, or post-change validation.

## Checklist
1. Confirm target project and branch.
2. Run security advisors.
3. Run performance advisors.
4. Map findings to concrete remediation actions.
5. Re-run advisors after changes.
6. Report remaining findings with severity and next action.

## Rules
- Treat advisor output as evidence, not optional metadata.
- Include remediation links when available.
- Do not expand task scope beyond requested fixes.
